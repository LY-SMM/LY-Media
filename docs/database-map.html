قاعدة ذهبية: لا تُعدَّل الأرصدة ولا تُحذف الطلبات من الواجهة. كل عملية مالية تمر عبر دالة SQL، وكل جدول محمي بـ RLS.
تحذير: حذف المزوّد يحذف خدماته نهائيًا. الطلبات تبقى محفوظة (المبلغ والكمية والهدف والحالة واسم الخدمة)، لكن رابط الخدمة يصبح NULL.
